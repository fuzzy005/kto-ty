# Эпизод

Тесты «кто ты из сериала». Сейчас в каталоге «Слово пацана» (1 сезон) и «Фишер» (1–3 сезоны). У каждого вопроса своя иллюстрация. В результате — герой, сезон и связь с ответами.

## Запуск

```bash
npm install
npm run dev
```

Проверка данных: `npm run check`. Сборка: `npm run build`.

## Как добавить категорию

В `src/data/categories.js` добавьте объект с `id`, `title` и `description`. Он станет новой вкладкой.

## Как добавить тест

1. Создайте файл в `src/data/tests/` по образцу `slovo-patsana.js`.
2. Подключите его в массив `tests` в `src/data/index.js`.
3. Для новой картинки добавьте функцию в `src/illustrations/QuestionArt.jsx` и укажите её имя в поле `scene`.

Картинки авторские. Кадры сериалов и портреты актёров не используются.
